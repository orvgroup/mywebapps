# ORV Automation Store

A static GitHub Pages catalogue of reusable GitHub Actions workflow templates.

**Live site:** https://orvgroup.github.io/mywebapps/automation-store/

## Features

- Search and category filters
- Free and Pro-pack labels
- In-browser YAML preview
- One-click YAML downloads and clipboard copy
- Local starter workflow builder for Python, Node.js and static websites
- Installation and monetization documentation

## Use a template

1. Open the catalogue and preview a workflow.
2. Download the YAML file.
3. Add it to your repository under `.github/workflows/`.
4. Review the workflow's permissions, triggers, action versions and placeholders.
5. Commit and inspect the Actions run.

## Important

The starter builder is a local rule-based generator, not a hosted AI service. No API key is needed. The Pro labels currently describe the planned paid pack; this repository does not yet enforce paid access or process payments. See [Monetization roadmap](docs/MONETIZATION.md).

All workflows are examples. Adapt them to your project and review third-party actions before use.
